## 🕹️ Overview

Desktop+ is a powerful SteamVR overlay providing window capture, multiple monitors, curved displays, 3D side-by-side rendering, and persistent per-app configurations.

Whether you're a newcomer or a veteran, Desktop+ provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Multi-Monitor** | View and interact with all your desktop monitors in VR space |
| **Curved Display** | Wrap desktop windows around you on a curved virtual screen |
| **3D Side-by-Side** | Render any desktop window in stereoscopic 3D |
| **Per-App Profiles** | Automatically switch overlay layouts for each VR application |
